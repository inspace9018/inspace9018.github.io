使用 Lookout 前须知

Lookout 会显示什么？

它是用于 Deadlock 的 Windows 叠加层，可显示野怪刷新计时、时间提醒、英雄信息和技能升级效果。可以在设置中选择显示项目。

免费吗？需要什么环境？

应用免费，在 Windows 上运行。请将 Deadlock 设为窗口或无边框窗口模式。仪表盘和网站含有广告。

不安装应用也能使用网站吗？

攻略、英雄信息与配装、阵容分析、地图和分路路线可在浏览器中查看。游戏内叠加层需要安装 Windows 应用。

如何读取游戏信息？

画面识别在本机进行。可选的游戏 HUD 联动使用游戏文件夹中的模组文件和配置，修改前会备份。不读取游戏内存、不注入 DLL、不篡改数据包。这是与 Valve 无关的玩家自制工具。

会降低多少帧率？

影响取决于电脑和开启的功能，无法保证固定的帧率变化。可在设置中查看 Lookout 的 CPU 使用率并关闭不需要的项目。从 0.1.14 起，按 F10 隐藏叠加层也会暂停画面识别。

可以隐藏或调整叠加层吗？

默认快捷键：F10 显示或隐藏，F11 查看小地图详情。可在设置中修改快捷键、显示项目、文字大小和背景浓度。

默认在本机识别画面，不改动游戏文件。可选的游戏 HUD 联动会在备份后安装一个模组文件，并向 gameinfo.gi 添加三行，可在仪表盘中移除。反馈截图仅在您选择图片并同意发送后传送。这是与 Valve 无关的玩家自制工具，不读取游戏内存。
