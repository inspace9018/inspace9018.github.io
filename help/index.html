룩아웃 설치와 오버레이가 안 뜰 때

Windows에 설치한 뒤 데드락을 창 모드나 테두리 없는 창 모드로 실행합니다. 화면이 뜨지 않으면 연결 상태, F10 표시 상태와 항목 설정부터 확인합니다.

룩아웃 FPS·CPU 사용량과 마우스 끊김 확인법

고정된 FPS 감소량은 아직 실측하지 않았습니다. CPU 사용률은 FPS와 다른 지표입니다. 아래는 실제 저장된 CPU 자료, 별도 창 테스트, 직접 비교하는 방법을 구분한 설명입니다.

데드락 정글 캠프 생성·재생성 시간

최초 생성은 경기 시작 후의 시각이고, 재생성은 캠프를 정리한 뒤의 간격입니다. 아래 표는 사이트에 포함된 정글 자료에서 읽은 값이며 자료 확인일을 함께 표시합니다.

→

데드락 난투와 일반 경기, 룩아웃 표시 차이

난투는 4 대 4, 일반 경기는 6 대 6으로 구분합니다. Lookout은 모드에 따라 표시 항목을 달리하며, 난투에서는 정글·상점 오버레이를 사용하지 않습니다.

→

데드락 능력 투자 효과를 Tab에서 확인하는 법

투자할 수 있는 능력 포인트가 있고 해당 업그레이드 칸이 화면에 보이면, Tab 화면에서 다음 단계의 효과를 확인할 수 있습니다. 표시 여부는 켠 항목과 화면 인식·HUD 연결 상태에 따라 달라집니다.

→
