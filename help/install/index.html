룩아웃 설치와 오버레이가 안 뜰 때

Windows에 설치한 뒤 데드락을 창 모드나 테두리 없는 창 모드로 실행합니다. 화면이 뜨지 않으면 연결 상태, F10 표시 상태와 항목 설정부터 확인합니다.

설치 순서

  1. 공식 다운로드 버튼에서 Lookout-Setup.exe를 받아 실행합니다. 설치·업데이트는 경기를 마친 뒤 진행합니다.
  2. 데드락을 창 모드 또는 테두리 없는 창 모드로 실행하고 대시보드의 게임 연결 상태를 확인합니다.
  3. 경기에 들어가 표시를 확인합니다. 기본 단축키 F10은 표시·숨기기, F11은 미니맵 자세히 보기입니다.

안 뜰 때 확인할 것

  1. 게임 창이 최소화되지 않았고 앞에 있는지 확인합니다. 다른 앱으로 전환하면 오버레이는 비켜납니다.
  2. F10으로 숨겨진 상태인지 확인하고, 설정에서 해당 화면의 표시 항목이 켜져 있는지 봅니다.
  3. 연결이 끊겼다면 대시보드에서 데드락 창을 다시 연결합니다. 연결됐는데 정보가 비면 화면에 해당 정보가 실제로 보이는지 확인합니다.

정확한 인식이 필요할 때

기본 화면 인식은 PC 안에서 처리합니다. 선택 기능인 게임 HUD 연동은 모드 파일 1개와 gameinfo.gi의 SearchPaths 3줄을 백업 후 적용하며 대시보드에서 제거할 수 있습니다. 비밀번호나 Steam 실행 옵션 변경은 필요하지 않습니다.
