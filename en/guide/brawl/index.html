Street Brawl vs normal Deadlock: Lookout displays

Street Brawl is 4v4 and a normal match is 6v6. Lookout changes its displays with the mode and does not use jungle or shop overlays in Brawl.

Item selection

The current choices are recognized by icon and name, with tier, pick-rate rank and a short description above each item. New choices are read after subsequent picks or rerolls.

Read tiers with sample sizes

Item tiers and ranks use pick rate. A high tier does not guarantee the best choice for a situation or a win. Missing hero-specific records are labeled as all-hero data, and small samples are identified.

If the mode looks wrong

Check the game screen and dashboard connection. With the optional HUD link, eight and twelve hero slots are used to identify Brawl and normal matches. This is the app detection method and should be checked against the actual game display.
