安装 Lookout 与叠加层不显示的排查

在 Windows 安装后，以窗口或无边框窗口模式运行 Deadlock。若不显示叠加层，先检查游戏连接、F10 显示状态和已开启的项目。

安装步骤

  1. 从官方下载链接下载并运行 Lookout-Setup.exe。请在对局结束后安装或更新。
  2. 以窗口或无边框窗口模式运行 Deadlock，并检查仪表盘的游戏连接状态。
  3. 进入对局检查显示。默认 F10 显示或隐藏，F11 查看小地图详情。

不显示时检查什么

  1. 确认游戏窗口未最小化并位于前台。切换到其他应用时叠加层会隐藏。
  2. 检查是否被 F10 隐藏，以及设置中当前画面的相关项目是否开启。
  3. 连接断开时，在仪表盘重新连接 Deadlock 窗口。已连接但没有信息时，检查对应信息是否确实显示在游戏画面中。

可选 HUD 联动

画面识别在本机进行。可选 HUD 联动会在备份后安装一个模组文件，并在 gameinfo.gi 中添加三行 SearchPaths，可在仪表盘中移除。不需要密码或修改 Steam 启动选项。
