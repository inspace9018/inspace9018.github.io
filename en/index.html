04

Common questions

What does Lookout show?

It is a Windows overlay for Deadlock with jungle respawn timers, timing alerts, hero information and ability-upgrade effects. Choose what to display in Settings.

Is it free, and what does it require?

The app is free and runs on Windows. Run Deadlock in windowed or borderless mode. The dashboard and website contain ads.

Can I use the website without installing the app?

The guide, hero information and builds, team composition tool, map and lane routes work in your browser. The in-game overlay requires the Windows app.

How does it read the game?

Screen recognition runs on this PC. The optional game HUD link uses a mod file and configuration in the game folder, with a backup before changes. It does not read game memory, inject DLLs or tamper with packets. This is a fan-made tool, not affiliated with Valve.

How much does it affect FPS?

It depends on your PC and enabled features; there is no guaranteed FPS figure. Settings shows Lookout CPU usage and lets you turn off unused features. From 0.1.14, hiding the overlay with F10 also pauses screen recognition.

Can I hide or customize the overlay?

Default shortcuts are F10 to show or hide and F11 for minimap detail. Settings lets you change shortcuts, visible elements, text size and background opacity.
