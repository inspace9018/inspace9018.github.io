룩아웃 FPS·CPU 사용량과 마우스 끊김 확인법

고정된 FPS 감소량은 아직 실측하지 않았습니다. CPU 사용률은 FPS와 다른 지표입니다. 아래는 실제 저장된 CPU 자료, 별도 창 테스트, 직접 비교하는 방법을 구분한 설명입니다.

확인 가능한 CPU 기록

0.1.14 이전의 경기 분류 저장 자료 360개를 보정한 근삿값입니다. i7-12700F, 논리 프로세서 20개인 한 PC의 기록이며 개선 전후 FPS 비교가 아닙니다.

전체 CPU 대비 룩아웃 비중. 저장 값의 반올림 때문에 정확한 복원은 불가능합니다. FPS나 마우스 지연으로 환산할 수 없습니다.

0.1.14에서 바뀐 것

쓰지 않던 마우스 이동 전달을 제거하고, 연결 중 15초마다 하던 창 목록 조회를 별도 창 감시로 바꿨습니다. F10으로 숨기면 화면 캡처와 글자 인식도 일시 중지합니다. CPU 사용량을 실제보다 낮게 표시하던 계산도 고쳤습니다.

0.1.14 변경 내역

같은 조건에서 비교하기

  1. 해상도, 그래픽 옵션, 프레임 제한과 비교할 장면을 고정합니다. 게임 업데이트와 PC 사양도 적습니다.
  2. Lookout 완전 종료 / 실행·오버레이 표시 / F10 숨김을 각각 비교합니다. 숨김은 프로그램 완전 종료와 조건이 다릅니다.
  3. 가능하면 평균 FPS뿐 아니라 낮은 프레임과 프레임 시간도 기록합니다. 같은 장면을 반복해 일시적인 전투 부하를 구분합니다.

끊김이 남아 있다면

설정에서 사용하지 않는 표시 항목을 끄고 CPU 변화를 확인합니다. 피드백 창에는 발생 상황, 표시·숨김 차이와 직접 확인한 FPS를 적을 수 있습니다. 진단 자료와 스크린샷은 내용을 확인하고 전송에 동의한 경우에만 보냅니다.
