2. 어깨 돌격

앞으로 돌격해 타격한 영웅에 끌어당기기 효과를 적용합니다. 영웅을 벽에 밀어붙이면 기절 효과를 적용합니다.돌격 중에 영웅과 충돌할 경우 이동 속도가 증가합니다.

상대할 때: 벽을 등지지 말고 돌진 경로에서 옆으로 비켜서세요

3. 저항의 불꽃

보너스 방어 속성을 획득합니다. 피해를 입으면 일시적으로 입은 피해량의 일부에 해당하는 재생 효과를 얻습니다.

상대할 때: 맞을수록 회복하니 짧게 몰아치거나 회복 감소를 쓰세요

4. 대지 강타 반경 9m

공중으로 높이 뛰어오른 후 지면을 강타해 마법 피해를 입히고 기절시킵니다.
